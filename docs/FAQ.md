# 常见问题

本文汇总轻小说文库下载器使用过程中较常见的问题和处理方法。

[返回项目首页](../README.md)

## 登录与网络

### 为什么无法登录、检索或下载？

轻小说文库禁止来自日本 IP 的访问。如果设备位于日本，或代理 / VPN 使用日本节点，登录、检索和下载可能失败。请切换到非日本 IP 的网络环境后重试。

如果当前并非日本 IP，可以按以下顺序排查：

1. 确认浏览器能够正常访问轻小说文库。
2. 前往应用的「配置」页面，检查账号和密码是否正确。
3. 点击「刷新登录状态」，成功后重新检索或下载。

### 提示登录状态失效或 HTTP 403 怎么办？

先确认当前网络不是日本 IP，然后前往「配置」页面点击「刷新登录状态」。当 Wenku8 返回安全验证页面时，应用会打开独立窗口；完成验证并进入轻小说文库首页后，窗口会自动关闭，后续检索、发现、封面和下载请求会继续复用同一会话。

如果验证窗口长时间停留在“正在进行安全验证”或“验证成功，正在等待响应”，请先用浏览器确认网站本身能否正常进入。浏览器也无法进入时，通常是目标网站或当前代理线路暂时无法完成验证，可切换非日本代理节点、临时关闭代理直连，或稍后再试。

验证通过后仍然失败时，请重新检查已保存的账号和密码。

登录状态会由目标站点定期更新，之前可以使用的状态也可能失效。

### 登录信息如何保存在本地？

账号、密码和 Cookie 会先由应用内置的固定算法加密，再写入本机的 `secrets.enc`。应用不会调用系统钥匙串，也不会要求输入系统密码；解密后的内容只在应用运行期间保存在内存中，修改登录信息或 Cookie 时才重新加密写入。

这种方式主要用于避免直接打开文件就能看到明文，不用于抵御能够读取程序文件和本机数据的攻击者。首次读取旧版 `safeStorage` 配置时，应用会先保留原文件备份，再自动创建空的新版敏感配置；旧凭证无法在不调用系统钥匙串的情况下转换，因此升级后需要重新填写账号密码。

### 提示操作太频繁或 HTTP 429 怎么办？

目标站点会限制短时间内的请求次数。请暂停操作并等待一段时间后再试，不要连续刷新、反复搜索或重复创建下载任务。应用会根据服务器响应自动放慢后续请求。

### 提示连接超时或网络连接失败怎么办？

请检查本机网络、代理和 VPN 设置，确认能够正常访问轻小说文库后再试。临时网络波动也可能导致请求超时，可以稍后重新操作。

## 检索与下载

### 为什么检索不到作品？

请先确认选择了正确的检索方式：

- 「编号检索」需要输入目标作品的小说编号。
- 「作者检索」和「书名检索」可以输入作者名或书名关键词。
- 搜索内容不能为空，且不能超过 100 个字。

如果关键词过于完整或包含多余符号，可以缩短关键词后重试。

### 下载失败后如何重试？

先根据页面提示处理网络、登录状态或下载目录问题，然后前往「下载历史」页面重新尝试失败的任务。

如果失败原因是登录状态失效，请先在「配置」页面刷新登录状态；如果提示操作太频繁，请等待一段时间后再重试。

关闭应用时，未完成的任务会标记为「已中断」，不会在下次启动时自动继续。应用会保留仍有效的作品资源缓存，可以在「下载历史」中重试原记录，减少重复请求。

### 为什么下载完成后仍提示部分内容缺失？

封面、插图等附加资源可能因临时网络问题未能保存。此时正文通常仍可正常阅读；如需完整资源，可以在网络恢复后重新下载。

## 文件与存储

### 搜索和作品内容会使用缓存吗？

搜索结果每次都会实时获取。打开具体作品时，应用会根据作品的更新时间、最新章节和连载状态复用尚未变化的目录与下载资源；点击详情页的「重新加载」会立即重新检查作品页和目录。

### 「清除缓存」会删除已下载内容吗？

不会。清除缓存只删除应用为加速作品加载和下载保存的临时数据，不会删除 EPUB、已下载插图、下载历史、设置或登录信息。正在下载的任务会先保留其正在使用的数据，并在任务结束后自动清理。

### 下载的 EPUB 和插图保存在哪里？

- 安装版默认保存在系统下载目录下的 `Wenku8Downloader` 文件夹。
- 开发版默认保存在项目的 `downloads` 目录。
- 可以在「配置」→「下载设置」中选择其他目录。

修改下载目录只影响之后创建的下载，已经下载的文件不会自动移动。

### 提示存储空间不足或没有文件访问权限怎么办？

- 存储空间不足：清理磁盘空间，或在「下载设置」中更换下载目录。
- 没有文件访问权限：选择当前用户具有写入权限的目录后重试。

如果文件夹已被移动或删除，请重新选择下载目录。

## 仍然无法解决

可以先重启应用并再次执行出现问题的操作。如果问题仍然存在，请在「配置」页面打开日志目录，保留出现问题时的应用版本、操作步骤和错误提示，以便进一步排查。

日志只保存在本机，不会自动上传。分享日志前仍建议检查并移除不希望公开的信息。
